# RPC methods

Call every method through `provider.request({ method, params })`. A request that isn't a single object, or has no method name, rejects with `-32600`.

## Refused — never supported

These reject with code `4200` and a message explaining why.

<MethodTable rows={[
  ["eth_sign", "Signs arbitrary bytes with no context — the bytes can be a transaction hash that drains the account."],
  ["eth_signTransaction", "Signing without broadcasting is not supported. Use eth_sendTransaction."],
  ["eth_signTypedData", "Legacy typed data (v1) has no domain separator and is replayable. Use v4."],
  ["eth_decrypt", "Deprecated: reuses the signing key for a second purpose."],
  ["eth_getEncryptionPublicKey", "Deprecated."],
  ["eth_coinbase", "Deprecated: conflicts with per-site account scoping. Use eth_accounts."],
  ["eth_sendRawTransaction", "Arbitrary raw broadcast is not proxied. Use eth_sendTransaction, or your own RPC."],
]} />

Any other method name also rejects with `4200`.

## Legacy API

`provider.enable()`, `provider.send()` and `provider.sendAsync()` exist so older dapps don't crash, but they aren't a supported API. Use `request()`.
